`scripts/verify_evidence.py` 逐格比對所有顯示數字與 findings/22：權重表 31 格、殘差 15 組向量、實算整句、餘弦表 30 格（含灰字是否等於 |餘弦| < 0.5）、每條邊的存在與否／數值／線寬／虛實、九行網路註記與解讀段落中的數字；最後將整個摺疊區的數字逐一比對，凡非來自 findings/22 也非代號、日期、門檻或章節號者即失敗。四種刻意竄改（a 改 18.1%、圖說加入未知數字、移動一條邊、改一個註記）均使檢查失敗。

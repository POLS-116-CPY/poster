## 3. 與論文一致性

**刻意與論文措辭不同之處：**

1. **規則驅動是「領先」解釋嗎？** issue 建議寫成主要候選解釋。論文 §11.1 寫的是「現有診斷不足以判定是哪一種機制」，§11.5 也提醒「被動持有者的共同持股不承載資訊」不能當作先驗解釋。因此海報把規則驅動列為第一個候選，但不說它是最可能的，並明寫「本研究未能區分」。白話句則採 issue 的框架（ETF 多買少買由規則決定）。這是對訊號意義的描述（論文 §5.1），不是對否證原因的歸因。
2. **「打九折」未採用。** 「預測乘 0.9 的 R² 比整套網路更高」只出現在 findings/12，量測於 U19 修正前，沒有寫進現行論文。現行論文的對應證據是 §9.1 的離散度匹配：18 格中 13 格可重現 100% 以上的增益。白話句改為「只把預測等比例縮小、不改任何排序，分數就可能變好」，描述機制而不引用該數值。
3. **白話句的簡化。** 「略差」「差不多」「沒有變得更準」是對點估計方向與排名 p 的白話描述，不帶數值。
4. **固定 0.01 界限的來源。** 海報只寫「敏感度界限」，未寫論文 §8.6 引的 Xu et al. (2021)、Li et al. (2024)。理由：版面，而且這兩篇與本研究市場不同。

**論文錯誤（未修改論文，請作者處理）：**

1. **§8.3 與 §9.5：規模分層虛無的偏誤方向寫反。** §8.3 寫「對到自己的股票保留真實的網路區塊，所以條件虛無略偏向真實結果，亦即對 M1 有利」，§9.5 寫「分層虛無本身略偏向 M1」，findings/25 第 3 節亦同。前半句（虛無更接近真實網路）正確，但結論方向相反：虛無混入約一成真實網路區塊後，更難顯示真實網路勝過虛無，檢定對 M1 偏保守，而不是有利。海報原文沿用了「略偏向 M1」，本 PR 已改為「虛無因此更接近真實網路，檢定略偏保守」。結論不受影響（排名 p 本來就不顯著）。
2. **§9.5 末句：「仍無一格的真實 ΔIC 落在 5% 尾端以外」字面上意思相反。** 照字面讀，每一格都落在 5% 尾端「之內」，即全部顯著。原意應為「無一格落在上側 5% 尾端內」（無一格排名 p < 0.05）。findings/25 第 3 節末句同。海報未使用此句。
3. **findings/25 第 3 節（非論文本文）：** 「XGBoost 在半導體 H=20／30 反覆出現 0.02–0.06 的排名 p」與 `25-cperm-ranks.csv` 不符。實際為 0.02–0.10，12 格中 5 格高於 0.06；論文 §9.5 已寫 0.02–0.10，正確。

另外核對了上述數字的來源完整性：三種基準的 `variant_ic.csv` 中，每格 M0／M1 各 99 次抽樣，沒有缺值也沒有重複列，所以海報引用的 0.09／0.08／0.19 不受 `issue25_cperm.py` 未檢查缺值的隱患影響。

**其餘抽查一致：**

- §13.4 的信賴區間上界（−0.0068 至 +0.0129）；
- §9.3 的排列中位數範圍；
- §8.6 的 0.013–0.022；
- §10.11 的 88／528 格；
- §9.6 的 P4 數字；
- §9.8 的 GAT 排序結果。
